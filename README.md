# JobFinder

**Topic:** Job Finding

## Group members

- Almansur Maxym, Adilbek Kairov (IT-2501)

## Description

JobFinder is a multi-page responsive website for finding jobs in Kazakhstan. Students, graduates and professionals can browse vacancies, see companies that are hiring and contact the platform. Employers can learn how to post their vacancies.

## Pages

- **Home** – hero section with a job search form, popular categories, featured jobs, how it works
- **Jobs** – job cards and a table with all vacancies
- **Companies** – list of companies that are hiring
- **About** – mission of the platform, advantages and statistics
- **Contact** – contact form and office information

## Features implemented

- Navigation bar with logo on all pages (Flexbox)
- Semantic HTML5: `header`, `nav`, `main`, `section`, `article`, `address`, `footer`
- Table with vacancies and two forms (job search and contact form)
- External stylesheet `css/style.css`, no inline or internal styles
- CSS variables in `:root` and the Poppins font from Google Fonts
- Layout with Flexbox (header, search form, social links) and CSS Grid (categories, statistics)
- Positioning: job type badge with `position: absolute` inside a card with `position: relative`
- `:hover` and `:focus` on buttons and links
- `:nth-child()` for alternating category items and table rows
- `loading="lazy"` on images below the fold
- Mobile-first responsive design with media queries for tablet (768px) and desktop (992px)
- Bootstrap grid and utility classes (containers, spacing, text alignment, buttons, display)
